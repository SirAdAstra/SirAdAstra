## 🚀 Projects & Experiments

A few highlights from my recent space expeditions:

### ✨ [Base-Trimmer](https://github.com/SirAdAstra/Base-Trimmer)
> **A Palworld mod that automatically hides grass and decorative foliage beneath player-built structures.**

A gameplay utility focused on keeping player bases clean by preventing vegetation from visually clipping through buildings.

* Geolocation detection with manual search fallback.
* Custom SVG weather icons.
* Modular JavaScript logic and CSS loading states.
